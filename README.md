## О проекте

**s21_matrix_oop** — это объектно-ориентированная библиотека для работы с матрицами, реализованная на C++17. Проект был выполнен в рамках учебного процесса в **School 21**. Библиотека предоставляет удобный класс `S21Matrix` с полным набором операций линейной алгебры:

- Конструкторы: по умолчанию, параметризованный, копирования и перемещения
- Деструктор
- Геттеры и изменение размера (resize)
- Арифметические операции:
  - Сравнение (`EqMatrix`, `operator==`)
  - Сложение и вычитание (`SumMatrix`, `SubMatrix`, операторы `+`, `-`)
  - Умножение на число и на матрицу (`MulNumber`, `MulMatrix`, операторы `*`, `*=`)
  - Транспонирование (`Transpose`)
  - Вычисление матрицы алгебраических дополнений (`CalcComplements`)
  - Определитель (`Determinant`)
  - Обратная матрица (`InverseMatrix`)
- Перегрузка операторов для естественного синтаксиса работы с матрицами
- Исключительная обработка ошибок с использованием `std::invalid_argument` и `std::out_of_range`

## Сборка и запуск

Для сборки статической библиотеки и запуска тестов воспользуйтесь Makefile:

```bash
# Собрать библиотеку и тестовый исполняемый файл
make all

# Запустить unit-тесты
make test

# Очистить промежуточные и итоговые файлы
make clean
```  
После `make all` будет создана статическая библиотека `s21_matrix_oop.a` и исполняемый файл с тестами.

## Использование библиотеки

```cpp
#include "s21_matrix_oop.h"

int main() {
    S21Matrix A(3, 3);
    S21Matrix B(3, 3);
    // Заполнение и операции
    A(0,0) = 1.0;
    // ...
    S21Matrix C = A + B;
    std::cout << "Определитель A: " << A.Determinant() << std::endl;
    return 0;
}
```

При компиляции добавьте флаг `-Iinclude` и линкуйтесь со статической библиотекой:
```bash
g++ -std=c++17 -Iinclude main.cpp ./s21_matrix_oop.a -o my_app
```
```bash
./my_app
```

## Тестирование

В проекте используются unit-тесты на базе Google Test. Они покрывают:

- Конструкторы и деструктор
- Операции сложения, вычитания, умножения (матрица и число)
- Транспонирование, определитель и обратная матрица
- Перегрузку операторов
- Обработка исключительных ситуаций

Для запуска тестов выполните:
```bash
make test
```
